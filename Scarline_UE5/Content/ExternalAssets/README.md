# External assets

Place imported assets into these folders in Unreal Content Browser:
- Vehicles: `/Game/Vehicles/`
- Track meshes and props: `/Game/Environment/Props/`
- PBR textures: `/Game/Environment/Textures/`
- Materials: `/Game/Environment/Materials/`

See `ASSET_SOURCES.md` for CC0 sources and licence notes. Binary assets are not bundled in this source-only delivery; use the asset links and import checklist in the project README.
